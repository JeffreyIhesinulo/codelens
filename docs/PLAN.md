# CodeLens — project plan (v3, 17 Nov 2026)

CodeLens is an AI-assisted app that teaches C (and a little C++) to **complete beginners**,
written in C++17 with raylib. Pair project: Dzheffriei (engine, `src/core`) and Ihor (UI, `src/ui`).

Detailed tasks: [plan-jeffrey.md](plan-jeffrey.md) · [plan-ihor.md](plan-ihor.md).
What changed between plan versions: [AGENTS.md → Plan change log](../AGENTS.md#plan-change-log).

## The idea in one paragraph

Every topic goes **Explore → Understand → Practice**. *Explore*: play with an interactive
picture of memory (sliders and buttons, no code to write). *Understand*: watch real code run line
by line with the memory visualizer and a plain-English sentence for every line, predict what
happens, fix a bug, explain in your own words. *Practice*: write code that passes tests, with an
AI tutor. The app always tells the student what to do next.

## Who it is for

Someone who has **never programmed**. They do not know what a variable, a compiler or `main` is.
Every design decision is checked against that person:

- Nothing appears before it is explained (addresses, the stack, the heap come later).
- Every screen answers "what do I do now?" with one visible instruction and one main button.
- The first lessons need no typing from scratch: watch, click, reorder, choose, then edit a few lines.
- Errors are explained in plain English, not shown as raw compiler output.

## What v3 adds

### A. Beginner-first teaching
1. **Progressive memory view** (`@show` per lesson/step): `values` (named boxes only) →
   `frames` (each function has its own boxes) → `addresses` (addresses + pointer arrows) → `heap`.
2. **One plain-English sentence per step**, generated by the engine from the difference between two
   snapshots: "Line 4: created x and put 3 in it", "x changed from 3 to 10", "entered swap(a, b)",
   "printed: 5 3", "reserved 12 bytes on the heap (block 1)". No AI needed, always correct.
3. **Explore for the first topics too**: a "box" scene for variables, an `if` scene where a slider
   changes `x` and the taken branch lights up.
4. **Scaffolding instead of a blank editor**: the template (`#include`, `int main`, `return 0`) is
   locked and greyed out, only marked lines are editable; new step kinds **order** (put shuffled
   lines in the right order) and **choose** (pick the right line / answer).
5. **Friendly compiler errors** from a fixed table (missing `;`, undeclared name, missing `}`, wrong
   `printf` format, `=` vs `==` warning, ...). AI only for the rest.
6. **Test with a real beginner** (15 minutes, someone who never programmed): note where they get stuck,
   fix it, put the findings in the report.

### B. A guided, friendlier interface
1. **Welcome screen on first launch**: what CodeLens is, the three stages, one button "Start lesson 1".
2. **Course map as a path**: topics in order, stage progress per topic, a big **Continue** button.
3. **A lesson opens on its first step, not on the editor.** One step at a time, full width:
   short text → the example or picture → one main button (Next / Check / Run).
4. **"What to do now" bar** always visible: `Step 3 of 8 · Predict · What is x after line 6?`.
5. **The editor appears only in steps where the student writes code.** Lesson notes stay reachable
   from Practice through a **Lesson notes** drawer.
6. **AI tutor** is a button ("Ask the tutor") in early steps and a panel in Practice.
7. **Glossary tooltips**: hover `printf`, `int`, `;`, `&`, `*` in code to see one-line explanations.

## Rules

- Each of us works in their own branch (`dzheffriei`, `ihor`) and merges into `main` through a
  reviewed pull request. After every merge: `git pull origin main` into your branch.
- `src/core` belongs to Dzheffriei, `src/ui` to Ihor. `src/core/app.h` is the contract between them:
  changing it is a separate PR both agree on.
- `./build/tests` must pass before a PR.
- A Development Journal entry after every working day.
